# طُمُوح | TMoh

منصة مذاكرة لطلاب الثانوية العامة والبكالوريا المصرية (واجهة أمامية + وسيط ذكاء اصطناعي اختياري).

## التشغيل على جهازك
ضع كل الملفات في فولدر واحد، ثم افتح `index.html`، أو شغّل `python -m http.server 8000` وافتح `http://localhost:8000`.

## النشر (مجاني)
GitHub Pages: ارفع كل الملفات في جذر المستودع وفعّل Pages من Settings.

## تفعيل المساعد الذكي (اختياري)
اتبع الخطوات المكتوبة أعلى `worker.js` (Cloudflare Workers + Gemini)، ثم ضع رابط الـ Worker في `CONFIG.AI_URL` أعلى `app.js`.
لا تضع مفتاح API في أي ملف من ملفات الموقع.

## المحتوى التعليمي
المواد لكل صف مأخوذة من إعلانات الوزارة كما نشرتها الصحف. الوحدات والدروس لا تُضاف إلا من كتب الوزارة:
الإعدادات → استيراد منهج رسمي (JSON) بالصيغة `{"المادة":[{"unit":"الوحدة","lessons":["الدرس"]}]}`.

## حدود معروفة
- البيانات محفوظة في متصفح الجهاز فقط (ليست حسابات آمنة ولا مزامنة). الإعدادات تتيح تصدير نسخة احتياطية واستيرادها.
- الاختبارات بلا بنك أسئلة، ولا توجد لوحة إدارة (تحتاج Backend مثل Supabase).
- "ملف عرض تجريبي" يحتوي بيانات وهمية معنونة بذلك، ويُحذف من الإعدادات.
